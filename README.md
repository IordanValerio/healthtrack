# HealthTrack 🩺

Projeto em desenvolvimento, criado para usar as ferramentas e habilidades que estou aprendendo no curso: CS50's Web Programming with Python and JavaScript. O **HealthTrack** é uma aplicação web desenvolvida com Django que tem como objetivo permitir que usuários calculem e acompanhem seu Índice de Massa Corporal (IMC).

🚧 **Status:** Em desenvolvimento

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento web. Ainda estou construindo e aprimorando suas funcionalidades, enquanto estudo sobre Python, Django, HTML, CSS e um pouco de JvaScript.

## ✨ Funcionalidades implementadas

- **Calculadora de IMC:** calcula o IMC com base na altura e no peso informados pelo usuário.
- **Classificação do IMC:** apresenta uma categoria de acordo com o resultado calculado.
- **Cadastro de usuários:** permite criar uma conta na aplicação.
- **Autenticação:** permite que usuários façam login.
- **Salvamento de resultados:** possibilita salvar os resultados de IMC no banco de dados para usuários autenticados.
- **Interface de histórico:** apresenta uma tabela com os registros de IMC salvos.
- **Interatividade:** utiliza JavaScript para mostrar e ocultar a área de histórico.

## 🔜 O que ainda vou fazer

Tenho que garantir que cada usuário tenha acesso somente aos seus próprios registros e que o sistema se comunique com o usuário através de mensagens de sucesso e de erro.
Além disso, também quero implementar uma página apenas sobre nutrição e outra apenas sobre Exercícios. Essas páginas poderiam sugerir tipos de alimentos e exercícios para os usuários. Para isso, elas iriam ter acesso ao histórico de IMC para sugerir o que for mais coerente para cada caso (de acordo com o imc do usuário).
E por fim, gostaria de melhorar a experiência do usuário tornando a interface mais agradável.
